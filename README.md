# LeakGuard — Сканер приватности

> Локальный инструмент для аудита приватности и базовой безопасности вашего ПК.

![License](https://img.shields.io/badge/license-MIT-blue.svg)
![Platform](https://img.shields.io/badge/platform-Windows%2010%2F11%20x64-blue)
![.NET](https://img.shields.io/badge/.NET-8.0-blue)

## Что это

LeakGuard помогает вам найти на компьютере файлы с персональными данными, чувствительные документы, потенциально опасные настройки и предлагает безопасные действия по исправлению.

**Это не троян, не средство обхода антивирусов и не инструмент для сбора чужих данных.**

## Возможности

- **Быстрое сканирование** — проверка основных папок за 1–5 минут
- **Полное сканирование** — глубокая проверка выбранных дисков
- **Настраиваемое сканирование** — выбор папок, расширений, исключений
- **Обнаружение ПДН** — email, телефоны, документы, ключи, токены
- **Метаданные изображений** — EXIF, GPS-координаты
- **Безопасные отчёты** — HTML, JSON с маскированием персональных данных
- **Шифрование отчётов** — DPAPI или пароль пользователя
- **Автозапуск** — опционально, через Планировщик задач Windows
- **Прозрачность** — каждый шаг требует вашего согласия

## Быстрый старт

### Сборка

```powershell
# Требования: .NET 8 SDK, Visual Studio 2022 или VS Code

# Клонировать репозиторий
git clone https://github.com/BitmofL/Win-scanner.git
cd Win-scanner

# Собрать решение
dotnet build Win-scanner.sln --configuration Debug

# Запустить
dotnet run --project src\LeakGuard.App\LeakGuard.App.csproj
```

### Portable-версия

```powershell
# Самодостаточная portable-сборка
dotnet publish src\LeakGuard.App\LeakGuard.App.csproj `
  -c Release `
  -r win-x64 `
  --self-contained true `
  -p:PublishSingleFile=true `
  -p:IncludeNativeLibrariesForSelfExtract=true `
  -o .\publish\

# Копируйте папку publish\ на флешку и запускайте LeakGuard.exe
```

### Тестирование на чистой VM

1. Создайте виртуальную машину Windows 10/11 x64 (Hyper-V, VirtualBox)
2. Установите .NET 8 Runtime (для portable) или .NET 8 SDK (для сборки)
3. Скопируйте LeakGuard.exe
4. Запустите — приложение работает без прав администратора
5. Проверьте, что:
   - Не создаёт сетевых подключений
   - Не требует UAC при запуске
   - Сохраняет настройки в `%APPDATA%\LeakGuard`

## Принцип работы

1. **Сканирование** — поиск паттернов ПДН в текстовых файлах, проверка имён файлов, метаданных изображений
2. **Оценка риска** — каждый результат получает уровень: Информация / Низкий / Средний / Высокий
3. **Рекомендации** — для каждого результата даётся безопасная рекомендация
4. **Экспорт** — отчёт с маскированием ПДН, опционально зашифрованный

## Безопасность

| Что делает | Как защищает |
|-----------|-------------|
| Сканирование файлов | Локально, без отправки данных |
| Экспорт отчётов | Маскирование ПДН, DPAPI шифрование |
| Автозапуск | Отключён по умолчанию, явное согласие |
| Интернет-проверки | Отключены по умолчанию, явное согласие |
| Логи | Без содержимого файлов, автоочистка |

## Удаление

1. Настройки → «Удалить все отчёты и кэш»
2. Удалите задачу автозапуска (если включена)
3. Удалите `%APPDATA%\LeakGuard`
4. Удалите `LeakGuard.exe`
