# Чек-лист релиза LeakGuard

## Предрелизная проверка

### Сборка
- [ ] `dotnet build Win-scanner.sln --configuration Release` — без ошибок и предупреждений
- [ ] `dotnet test src/LeakGuard.Tests/LeakGuard.Tests.csproj` — все тесты зелёные
- [ ] Portable-версия собирается: `dotnet publish ... -r win-x64 --self-contained`
- [ ] Размер portable-версии < 50 МБ

### Файлы
- [ ] Все исполняемые файлы имеют SHA256-хеши
- [ ] SBOM сгенерирован (dotnet-sbom)
- [ ] README.md актуален
- [ ] VERSION актуален (0.1.0)

### Безопасность
- [ ] Нет секретов/ключей в репозитории (`git grep -n "password\|secret\|token" -- src/ | grep -v "PatternLibrary\|DataMasker"`)
- [ ] Нет персональных данных в тестах
- [ ] Нет хардкод-путей к системным папкам
- [ ] UAC-запросы работают корректно
- [ ] Приложение запускается без прав администратора

### Функциональность
- [ ] Быстрое сканирование работает
- [ ] Полное сканирование показывает предупреждение
- [ ] Результаты отображаются с фильтрами
- [ ] Экспорт HTML генерирует валидный файл
- [ ] Экспорт JSON содержит правильную структуру
- [ ] Маскирование email, телефона, документов работает
- [ ] DPAPI-шифрование отчётов работает
- [ ] Автозапуск включается/отключается
- [ ] Удаление отчётов работает
- [ ] Навигация между страницами работает

### Тестирование на VM
- [ ] Windows 10 x64 — запуск без ошибок
- [ ] Windows 11 x64 — запуск без ошибок
- [ ] Portable-версия с флешки — работает
- [ ] Нет сетевых подключений при сканировании
- [ ] Настройки сохраняются в %APPDATA%\LeakGuard
