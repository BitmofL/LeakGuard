# Политика конфиденциальности LeakGuard

**Последнее обновление:** 03.10.2026  
**Версия:** 0.1.0

## 1. Введение

LeakGuard — это локальное desktop-приложение для Windows, предназначенное для самостоятельного аудита приватности данных на вашем компьютере.

Настоящая политика описывает, какие данные собираются, как используются и защищаются.

## 2. Принцип минимизации данных

LeakGuard придерживается принципа минимизации данных:

- Приложение **не собирает** персональные данные без необходимости
- Приложение **не отправляет** данные в интернет по умолчанию
- Приложение **не хранит** содержимое файлов в логах или отчётах без вашего ведома

## 3. Локальная работа

### 3.1 Сканирование
- Все операции сканирования выполняются **локально** на вашем устройстве
- Содержимое файлов анализируется в оперативной памяти
- Файлы не копируются, не отправляются и не загружаются на внешние серверы

### 3.2 Настройки
- Настройки хранятся в `%APPDATA%\LeakGuard\settings.json`
- Это локальный файл, доступный только вам
- Настройки не синхронизируются и не передаются

### 3.3 Логи
- Логи хранятся в `%APPDATA%\LeakGuard\Logs\`
- Логи содержат только технические сообщения (время, уровень, категория)
- **Не содержат** содержимого файлов, персональных данных, путей к чувствительным файлам
- Логи можно отключить полностью
- Логи автоматически очищаются по настройке

### 3.4 Отчёты
- Отчёты сохраняются **только локально** по вашему выбору
- Персональные данные в отчётах **маскируются по умолчанию**
- Отчёты можно зашифровать с помощью DPAPI или пароля
- Вы полностью контролируете хранение и удаление отчётов

## 4. Интернет-функции

### 4.1 По умолчанию отключены
Все функции, требующие доступа в интернет, **отключены по умолчанию**.

### 4.2 При активации
Если вы включите интернет-проверки:
- Будет запрошено **явное согласие** при каждом запросе
- В полном виде email/идентификатор **не передаётся** — только хеш
- Результат показывается без сохранения
- Вы можете отключить функцию в любой момент

## 5. Автозапуск

- Автозапуск **отключён по умолчанию**
- При включении создаётся задача в Планировщике задач Windows
- Запускается только лёгкий модуль уведомлений без сканирования
- Вы можете отключить или удалить задачу в любой момент

## 6. Права доступа

- Приложение запускается **без прав администратора**
- Для функций, требующих повышенных прав, показывается объяснение и вызывается стандартное окно UAC Windows
- При отказе от UAC приложение продолжает работать в ограниченном режиме

## 7. Удаление данных

Вы можете в любой момент:
- Удалить все отчёты и кэш через настройки
- Удалить задачу автозапуска
- Удалить папку `%APPDATA%\LeakGuard`
- Удалить исполняемый файл

После удаления приложение не хранит никаких данных.

## 8. Третьи стороны

LeakGuard **не передаёт** данные третьим лицам, за исключением:
- Интернет-проверок (если вы явно включили и согласились)
- Ссылок на GitHub (открываются в браузере, не через приложение)

## 9. Изменения политики

Мы можем обновлять эту политику. Значимые изменения будут отображены в репозитории и в приложении.
